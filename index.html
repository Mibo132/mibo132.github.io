Google Maps

The map is Google Maps. Without an API key, Google dims it and marks it “for development purposes only”. A key from your own Google Cloud account removes that.

API Key

Map ID (Optional)

With a key, the game uses Google's vector map, which follows your phone's light or dark mode. Leave this empty to use Google's demo map ID.

How to Get a Key

1
In Google Cloud Console, create a project and link a billing account. Google includes free monthly map loads, which cover testing.
2
Enable the Maps JavaScript API.
3
Under Keys & Credentials, create an API key.
4
Restrict the key to the website and to the Maps JavaScript API.
5
Paste the key above and tap Save.
Open Google Cloud Console

Allow Location Access

1
In Safari, open the page menu next to the address (aA or ⋯), then tap Website Settings → Location → Allow.
2
In Settings → Privacy & Security → Location Services, make sure Location Services is on and Safari Websites is set to While Using the App.
3
Come back here and tap Try Again.

Pages inside other apps, like the Claude app, can't use your location. Open the game's address in Safari.
