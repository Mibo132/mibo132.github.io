# Clash of Cities: web test build

A GPS territory strategy game on Google Maps. Claim real-world hexes, build on them and walk to use them.

Play: **https://mibo132.github.io** (Safari on iPhone; allow location access).

This repository only hosts the built website. The source is `prototype/web` in the main game repository. Rebuild there with `python3 prototype/web/build.py`, then copy `site/` here.
